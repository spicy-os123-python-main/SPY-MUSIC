## ✨ Features

- 🎧 **All Platforms & Artists in One Place:** Stream songs, albums, artists and playlists werbefrei (YouTube Music & Piped engine).
- 🔥 **Dual Flame Design:** Modern AMOLED Dark theme with glowing Electric Blue & Burning Crimson Red accents.
- 📱 **Android Background Playback:** Music plays smoothly when screen is locked or while multitasking (Android Foreground Service).
- 💬 **Discord Rich Presence:** Zeigt deinen Freunden in Discord in Echtzeit an, was du gerade auf SPY MUSIC hörst ("Listening to ...").
- 🚀 **100% Standalone Client:** Keine Website nötig, keine laufenden Serverkosten, keine Datenspionage.
- ⬇️ **Offline Downloads:** Lade Songs und Playlists direkt herunter.

## 📲 Android APK Download & Installation

### Option 1: GitHub Releases (Fertige APK)
1. Gehe auf **Releases** in diesem Repository.
2. Lade dir die neueste `SPY-MUSIC-release.apk` auf dein Smartphone herunter.
3. Öffne die Datei auf deinem Handy und erlaube die Installation.

### Option 2: Automatisch mit GitHub Actions bauen
Sobald Code auf `main` gepusht wird, baut GitHub Actions automatisch eine frische APK unter dem Tab **Actions** -> **Build SPY MUSIC APK**.

---

## 💻 Auf PC (Linux) ausführen

Voraussetzung: Flutter SDK installiert.

```bash
# Abhängigkeiten laden
flutter pub get

# Auf Linux Desktop starten
flutter run -d linux
```
